# Upwork skills-only package

<!-- Package template: this file becomes the archive-root README; links resolve from that root. -->

This archive contains instruction workflows, client manifests, support resources and documentation.
It does **not** contain a native connector, `bin/`, launchers, saved proxies, credentials or a hosted
MCP registration. No compiler or connector installation is needed to use pasted evidence.

## Start here

1. Read [client installation instructions](docs/skills.md) and choose your actual client/surface.
2. Load `skills/upwork-project-selection/SKILL.md` for job assessment, or
   `skills/upwork-profile-management/SKILL.md` for requested profile drafting.
3. For offline work, paste the relevant facts. Unknown facts remain unknown; no account tool is called.
4. For live reads or publication, configure a separately authorized MCP connection. Installing this
   package grants no account permission and cannot replace the workflow's two publication approvals.

Client manifests share the same `skills/` payload. Structural validation is not proof of native runtime
loading; [verification limits](docs/skills.md#installation-boundaries) identify missing evidence. The
portable OpenAI `Read` presentation is metadata, not an enforcement boundary or sandbox.

For the native connector and its operating-system prerequisites, download the separate platform
archive from the [project releases](https://github.com/KiaroSama/Upwork-Agent-Plugin/releases/latest).
The standalone plugin ZIP intentionally has a different README from that platform archive.
